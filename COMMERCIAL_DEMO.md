# TerraSync Commercial Demo

This package extends the MVP into a commercial presentation layer with:
- login and role-aware demo accounts
- inspector profile and credentials
- client/project assignment workflow
- client-supplied and on-site-created equipment inventory
- generic equipment fields for telecom, power, solar and utilities
- capture-only camera evidence
- GPS/time-only photo watermark
- aggressive evidence compression for large reports
- AI review queue
- offline queue and PWA shell
- PDF report integration through the existing backend
